## Structure

### Front-end

Three main pages:
 - Home (`index.html`) detailing my skills;
 - About Me (`about_me.html`) detailing my education and my experience;
 - Portfolio (`portfolio.html`) giving a chosen overview of my projects.

### Back-end

Several files and folders:
 - Assets folder holding all relevant non script files;
 - Commons (`commons.html`) holding the common part of the front-end files, i.e.: the header with the nav;
 - CSS and JavaScript files (`styles.css` and `js_functions.js`) to complete the plain html files.
